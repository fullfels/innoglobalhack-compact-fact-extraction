# Техническая спецификация прототипа

## Цель и границы

Из входного русскоязычного диалога с ASR-шумом получить факты о состоянии, тарифах, действиях, заявках и договорённостях; сохранить источник, говорящего, полярность и время. Одна обученная компактная decoder-модель, общая постобработка, API и локальное демонстрационное UI. Обучение с нуля, авторизация, биллинг, многопользовательская платформа и собственный ASR в объём хакатона не входят.

Приёмка: полное покрытие входных call_id, 100% финальных ответов соответствуют схеме, все официальные метрики посчитаны неизменным evaluator, минимум три воспроизводимые точки, измерения CPU/GPU с явным статусом недоступного оборудования. Качество и ресурсы — gates из 01; заранее гарантировать их достижение нельзя.

## Входной контракт CallInput v1

Pydantic-модели будущей реализации: `Turn(idx: int >=0, speaker: Literal[client,operator], text: str)`, `Series(account_id: str, call_index: int>=0, series_len: int>=1)`, `CallInput(call_id: str, started_at: datetime, duration_sec: int>=0 | None, series: Series | None, turns: list[Turn], noise_level: float | None)`.

Обязательны call_id, started_at и непустой turns; idx уникальны, порядок соответствует последовательности диалога, но idx не обязан совпадать с позицией массива. Передача `facts` запрещена для публичного inference; evaluator/export читает gold отдельно. started_at без timezone сохраняется как локальное время корпуса: не добавлять UTC и не сдвигать день. Лимиты тела 256 KiB, до 500 реплик — предварительные защитные настройки, проверить по реальным hidden требованиям; не обрезать silently. Переполнение контекста решает стратегия окон, не удаление последних реплик.

## Факт и результат

`ObjectRef(name: непустая строка, id: str | None, type: Literal[service,device,ticket,client] | None)`; `Source(turn_idx: int, span: tuple[int,int] | None, quote: str | None)`; `Fact(object: ObjectRef, attribute: Literal[service_state,tariff,ticket_status,action,agreement], value: непустая строка, polarity: Literal[-1,1], speaker: Literal[client,operator], valid_from: datetime, valid_to: datetime | None, source: Source)`.

source.turn_idx должен существовать во входе; speaker берётся из этой реплики. span — полуинтервал Python-символов `[start,end)`, 0≤start<end≤len(original_text); quote при наличии равен original_text[start:end]. Если надёжного спана нет — оба null. Значения не ограничивать enum каталога: реальные action содержат «— не помогло», agreement — свободный текст. confirmed из gold — дополнительное поле разметки, не обязательное поле минимального prediction; внутренний статус подтверждения держать отдельно.

Минимальный официальный prediction: call_id и facts с object.name, attribute, value, polarity, valid_from, valid_to, source.turn_idx. Наш экспорт сохраняет исходные метаданные и turns и добавляет facts. Object id детерминированный внутри аккаунта, без попыток угадать секретный gold id; он полезен продукту, но match_facts его не использует.

`ExtractResponse` содержит `prediction` (официальный CallPrediction), `meta` (request_id, model_id, manifest_id, mode, elapsed_ms, warnings, schema_valid, is_mock). Только prediction экспортируется в официальный JSONL. Не смешивать служебные ошибки с facts.

## Семантика

Утверждение оператора может быть фактом (например, зарегистрированная заявка); предложение или отвергнутая догадка — нет. Agreement требует подтверждения в контексте, иногда следующей репликой. «Не работает» — положительное утверждение симптома, а не автоматическое polarity=-1. Отрицания проверяются по области действия. Новое состояние закрывает старое только при уверенности, что это тот же объект и взаимоисключающий атрибут; не закрывать все service_state в звонке. Не выдумывать точную дату при неоднозначности: выбрать документированную конвенцию с warning либо оставить модельную дату, а не подставлять gold.

## HTTP API

| Endpoint | Контракт | Ошибки |
|---|---|---|
| POST /extract | CallInput → ExtractResponse, конфигурация из allowlist сервера | 413 размер, 422 схема, 429 очередь, 503 не готова модель/OOM, 504 timeout |
| GET /health | process_alive, model_state=unloaded/loading/ready/failed, ready, is_mock | 503 если real backend не готов; mock ready с явной меткой |
| GET /model/info | model_id, artifact/revision/hash, параметры, dtype, engine, context, limits, manifest | Не включать секреты и внутренние пути |
| POST /extract/batch (P1) | массив CallInput → результаты по call_id | индивидуальный статус; inference той же функцией |

Один model worker на GPU, один процесс FastAPI; очередь 8 запросов, concurrency inference=1 как стартовые настройки. Больше uvicorn workers создаёт копии весов и не является бесплатным ускорением. Startup warm loading по умолчанию; optional lazy loading через общий lock, readiness false до окончания. HTTP timeout стартово 120 секунд, очередь отдельно ≤30 секунд; реальные значения установить после p95. Async timeout не останавливает CUDA: worker должен поддерживать cooperative stopping или изоляцию/перезапуск процесса после зависания. Повторять запрос только по явному request_id, не накапливать скрытые retry.

Логи JSON: request_id, hash call_id, model/конфигурация, число токенов/фактов, фазы времени, error_code. Тексты и ФИО не логировать по умолчанию. Сбор локальных обезличенных метрик без внешних сервисов. Детали concurrency и ресурсных измерений в 11.

## Demo UI

Одна страница: структурированный ввод (started_at и реплики с speaker), готовые проверенные примеры, запуск, статус модели и реальное время запроса; таблица фактов; клик по факту подсвечивает исходную реплику; speaker/polarity; временная шкала состояний по объекту; вкладка raw JSON. Исходные тексты не заменять нормализованными. Сравнение A/B/C — P1: прежде всего загрузка сохранённых результатов, одновременная загрузка трёх моделей не нужна. Измеренные офлайн показатели подписывать dataset/hardware/manifest; не представлять их как время текущего запроса. Mock и replay явно обозначены.

## Acceptance и артефакты

Версия модели считается готовой только после загрузки из экспортированного каталога, прохождения всех 383 звонков без потери ID, schema validation и повторного evaluator. Качество экспериментальное, отказ при ошибке не превращать в успех через facts=[]. Резерв facts=[] допустим только как помеченный технический fallback, включённый в число неуспехов и метрики. UI и API обязаны показывать его статус. Измеренная производительность не обещается до benchmark.
