# B26 DSAI — итоговый снимок CompactFactExtraction

Код выбранной Qwen3-0.6B + LoRA +500, приложения и экспериментов, 16 ноября 2026. Этот каталог — отдельный зафиксированный снимок; код в корне репозитория сохранён.

- `source/app/`: FastAPI, frontend, Qwen bridge, постобработка. Для настоящей модели использовать **Dockerfile.release**; обычный Dockerfile — исторический mock-профиль.
- `source/training_and_evaluation/`: этапы обучения, официальной оценки и ресурсного пилота.
- `reports/`: измеренные метрики, протоколы и ограничения.
- `SOURCE_MANIFEST.json`: SHA-256 опубликованных файлов и исключения относительно локального комплекта.

Веса, tokenizer-артефакты, Docker tar, видео, исходные разговоры и полные обучающие payloads передаются отдельно через разрешённый организаторами облачный комплект. Они не включены в Git. Для запуска и воспроизведения нужны соответствующие артефакты; этот снимок кода сам по себе их не заменяет.
