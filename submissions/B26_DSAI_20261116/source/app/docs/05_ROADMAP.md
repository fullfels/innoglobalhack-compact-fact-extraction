## Критический путь

Контракт → train-ready+доступный checkpoint/GPU → pilot → один SFT → A export → B/C или альтернативные режимы → три full-val+ресурсы → выбор → Docker clean smoke → отчёт и сдача. Mock UI/Docker и normalizers идут параллельно и не блокируют SFT. Ресурсный baseline от организаторов — внешняя зависимость доказательства экономии, но не разработки.
