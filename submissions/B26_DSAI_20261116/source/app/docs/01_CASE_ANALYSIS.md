## Ограничения качества

Официальное правило: падение temporal и state ≤0.02, одновременно параметры сокращены ≥10× ИЛИ GPU-секунды/звонок ≥5×. Падение temporal >0.05 — исключение независимо от экономии. Результат скрытого теста не известен.

| Условие | По опубликованной базе | По пересчёту |
|---|---:|---:|
| temporal ≥ baseline−0.02 | 0.3961 | 0.4005 |
| state ≥ baseline−0.02 | 0.3283 | 0.2994 |
| temporal: граница baseline−0.05 | 0.3661 | 0.3705 |

До уточнения используем консервативные рабочие gates: temporal≥0.4005, state≥0.3283; это внутреннее решение, не новый официальный порог. В отчёте показываем обе базы. Желательный внутренний прирост +0.02 — отдельная цель (по пересчёту 0.4405 и 0.3394), не обязательный критерий. Разница B/C относительно A получается из измерений, не задаётся заранее.

Ресурсные сведения baseline отсутствуют: название glm-5.3 в README не доказывает параметры и GPU-время конкретного запуска. Нельзя заявлять 10×/5× или экономию денег без доказательства. Нужны сведения организаторов либо честный статус «не подтверждено».
